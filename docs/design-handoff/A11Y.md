# Wideline accessibility pass · WCAG 2.2 AA

Design-level audit of the Floodlight system, run on 31 Oct 2026 against the six design files and the token export. Ratios are calculated from the exact token values. Re-check them in code with axe or Lighthouse, because real rendering and real content can differ.

**The one known exception.** Lime `brand` on a white panel is 1.3:1. It is never used as text. On light surfaces every lime fill carries a 1px `brand-edge` border (ink), and that border is what meets 3:1. Never remove `border-brand-edge` from a primary button.

**Exempt.** `ink-disabled` is exempt from 1.4.3. Disabled controls also say why they're disabled in nearby text ("Set full time to continue", "32 left").

## 3. Focus (2.4.7, 2.4.11, 2.4.13)

- A 2px ring with a 2px offset on every focusable element: `:focus-visible { outline: 2px solid var(--wl-color-focus) }`. It is lime on dark and ink on light, and passes 3:1 on every surface.
- **Fixed in this pass:** the design files hard-coded a lime ring. On light surfaces that would have been 1.3:1. They now read `var(--focus)`.
- Selection and focus are separate. In the review list, J and K move the **selection** (selected fill plus a 1px focus-colour inset). Tab focus is a separate 2px inset ring. Both can show at once.
- Sticky headers, the toast region and the upload strip must not cover the focused element (2.4.11). Use `scroll-padding-top: var(--wl-shell-topbar)` on scroll containers.

## 4. Target size (2.5.8) and touch

- **Minimum below 768px is 44 × 44px** (`control-l`). Phone primary actions and guardian answers use 56px (`control-xl`). The guardian yes and no answers are 64px.
- **Fixed in this pass:** "Forgot password?" on the phone sign-in had a 28px hit area. It is now 44px.
- The 32px `control-s` is allowed only in desktop tables (row actions, pagination). On touch, the whole row is the target.
- The position chip in the phone lineup (28px) isn't a separate target. The whole 60px row opens the player editor.

## 5. Keyboard (2.1.1, 2.1.4)

Review workspace. Every shortcut has a visible button with its key printed on it. Single-key shortcuts only work while focus is inside the workspace and not in a text field. They can be turned off in Keyboard shortcuts (`?`), as 2.1.4 requires.

| Key | Action | Visible control |
|---|---|---|
| J / K | Next / previous event | Next / Previous buttons |
| Y | Confirm, then jump to the next pending event | Confirm |
| N | Reject, then jump to the next pending event | Reject |
| E | Edit selected event | Edit |
| A | Add missed event at the current time | Add missed event |
| U or Ctrl+Z | Undo the last decision | Undo in toast |
| Space | Play / pause | Play button |
| ← / → | 5 s back / forward (markers step: 1 s, Shift for 10 s) | Rewind / forward buttons |
| M | Set selected marker (upload step 3) | "Set … to mm:ss" button |
| ? | Shortcut list | Keyboard button in header |

Tabs use arrow keys between tabs and Tab into the panel. Menus and the organisation switcher use arrow keys, Enter and Esc. Modals trap focus, return focus to their trigger, and close on Esc.

## 6. Motion (2.3.3, 2.2.2)

- Only these move: hover and press colour changes (100ms), menus (150ms), modal entrance (240ms) and the 600ms save flash.
- `prefers-reduced-motion` sets every duration to 0. The loader icon stops spinning, and the save flash becomes a check icon that stays for 1.2s.
- Numbers never count up. Countdowns update once a minute, never every second.
- Loading uses static blocks, not shimmer.

## 7. Structure and announcements

- Status changes use `role="status"`: the upload strip, the expiry banner, save toasts, loading. Errors use `role="alert"`: sign-in error, validation summary, failed processing, the under-24-hours expiry banner. The countdown is announced on page load and when its step changes, not every minute.
- Icon-only buttons have `aria-label`. Status discs and icon-only consent badges have a text tooltip and an accessible name.
- Heatmaps are `role="img"` with an `aria-label` listing the top zones.
- Segmented filters are `radiogroup` / `radio`. Page tabs are `tablist` / `tab`. The current nav item has `aria-current="page"`.
- Tables keep `<th scope="col">`. Sorted columns set `aria-sort`.

## 8. Language (3.1.5, guardian screens)

Guardian copy is written for a reading age of about 12: one idea per sentence, everyday words ("stats", "say yes", "stop sharing"), no legal text on the main path. Body text is 18px and titles are 30px. Before launch, test the copy with guardians in English, isiZulu, Sesotho and Afrikaans, and translate it where the clubs need it.
