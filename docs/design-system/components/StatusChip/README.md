A chip shows the state of an event, a match or a job. Every chip pairs a colour with a word and an icon.

- **Provide:** the state word, up to two words. Event states are Confirmed, Auto-accepted, Pending review, Rejected and Manual. Match states are Draft, Uploading, Processing, Awaiting review, In review and Published.
- **Tones:** `--ok` for done or trusted, `--warn` for needs attention, `--danger` for rejected or failed, `--neutral` for in progress or inactive, and `--new` (floodlight) for just-arrived items, at most once per list.
- **Don't:** make chips clickable. Use a filter toggle or button instead.
