A card summarises one player in search results, shortlists and squad lists.

- **Provide:** the player's name, position, age group, preferred foot, club (or "No current club" for a departed player), consent state (club views only), and up to 4 key stats chosen for the position.
- **Avatar:** the player's initials on `pitch-soft`. Never use a photo.
- **Actions:** a hover or long-press menu offers "Add to shortlist" and "View profile". The whole card links to the profile.
- **Departed players:** show "Former club: …" in `ink-muted`. The stats stay.
