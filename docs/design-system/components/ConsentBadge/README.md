A badge shows a player's consent state. It appears on every player row, card and profile hero that club staff see.

- **Provide:** one of the five consent states: none, requested, club-only, scout-visible or withdrawn. The badge labels them No consent, Requested, Club only, Scout-visible and Withdrawn.
- **Pairing:** scout-visible uses `--ok` with a shield-check icon, club only `--neutral` with a shield, requested `--warn` with an hourglass, withdrawn `--danger` with shield-off, and none `--neutral` with no icon.
- **Placement:** in player cards and tables it sits next to the name or in its own column. On a profile it sits in the hero, with a "Manage consent" link for guardians.
- **Rule:** scouts never see this badge, because they only ever see scout-visible players.
