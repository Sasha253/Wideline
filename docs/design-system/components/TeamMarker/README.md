A marker shows which side a player, track or event belongs to. The UI never uses real kit colours.

- **Provide:** the side (home or away) and the team name, which can be shortened in dense rows.
- **Shapes:** home is a solid `home` (blue) square with an H. Away is an outlined `away` (orange) square with an A. They differ in shape and letter as well as colour, so they work in greyscale.
- **Use in:** lineups, track overlays on video, event rows and match headers. The same blue and orange outline player boxes on the video overlay.
