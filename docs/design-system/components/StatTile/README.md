A tile is the headline stat on a profile or squad dashboard. The whole tile links to the events and clips behind it.

- **Provide:** the label (from the stats catalogue), the value, the unit or qualifier, and the sample (match count, plus minutes where it is a per-90 rate).
- **Small samples:** under 3 matches, add `wl-stat__sample--small` and write "Small sample · N matches". The number still shows.
- **Layout:** tiles sit in a row of 3 or 4 on desktop and a 2-column grid on phones. The number is set in `stat-xl` with tabular figures.
- **Don't:** colour a number by whether it is "good", animate it counting up, or show a stat that has no traceable events.
